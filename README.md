# TinyUSB CDC Status

## Overview

TinyUSB CDC integration is currently **under test** and is already **working with CMake-based builds**.

At the moment:

- **CDC tests are ongoing**
- **CDC is working**
- validated with **CMake**
- **not yet working with Arduino IDE**

## Current Status

The current implementation has been tested successfully with a CMake workflow.

The example project includes a generated `CMakeLists.txt` that can be used as a starting point, but it is **not yet ready for direct Arduino IDE usage**.

## How to Test for Now

For now, the recommended workflow is:

1. **Clone this repository**
2. Go to the example folder
3. Open the provided `CMakeLists.txt`
4. Make a few **small local path adjustments**, such as:
   - `CORE_PATH`
   - `USER_LIBS`
   - `BOARDNAME`
5. Configure and build with CMake

## Notes About the Example `CMakeLists.txt`

The provided `CMakeLists.txt` was autogenerated and works as a good base for testing, but it may require machine-specific edits before building.

In particular, check these values:

- STM32Duino core path
- Arduino user libraries path
- selected board name

## Current Build Configuration

The validated TinyUSB CDC test setup currently uses:

- `USE_TINYUSB`
- `HAL_PCD_MODULE_ENABLED`

and depends on:

- `tinyusb`

## Arduino IDE Support

Arduino IDE integration is **still in progress**.

So at this stage:

- CMake workflow: **working**
- Arduino IDE workflow: **not ready yet**

## Summary

If you want to test TinyUSB CDC **right now**, please use the **CMake flow**:

- clone the repository
- update a few paths in the example `CMakeLists.txt`
- build and run from CMake
